# Contributing to Spatialfolio

Thank you for helping improve Spatialfolio.

## Good contributions

- accessibility and keyboard-navigation improvements;
- performance fixes for mobile and integrated GPUs;
- clearer documentation and validation messages;
- browser compatibility fixes;
- discipline-specific Canvas modes with a defensible scientific visual grammar;
- reusable project-page patterns that remain concise.

## Before opening a pull request

1. Keep the template dependency-free unless a dependency has a clear, documented benefit.
2. Do not add real personal data, copyrighted paper figures or private research assets to sample content.
3. Preserve reduced-motion behavior and the attribution credit.
4. Run `npm run validate`.
5. Test at approximately 390 px, 768 px and 1440 px widths.
6. Explain the scientific meaning of any new persistent visual element or animation.

For substantial visual changes, include screenshots or a short recording and describe pointer, touch and click behavior.
